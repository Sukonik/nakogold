# NAKO GOLD — Official images

All image files in this directory are artist-supplied or artist-approved derivatives of assets provided for the NAKO GOLD website.

- `nako-gold/artist-portrait.webp`: enhanced neon portrait, approved primary headshot.
- `nako-gold/portrait-artist-original.webp`: alternate artist portrait.
- `art/album-01-car.webp`: original featured car illustration for Spotify album https://open.spotify.com/album/5E4aD14AQmhQ1mmQZN985G.
- `logos/`: metallic gold, neon, and iridescent NAKO GOLD wordmarks.
- `live/`: creative performance-style concept visuals, not claims about specific verified shows.

Optimized WebP for speedy mobile delivery; keep original full-resolution source files separately.

**Naming note:** `logos/nako-gold-neon.webp` is the clean polished-gold wordmark on black (used in the gallery); `logos/nako-gold-24k.webp` is the rainbow-texture version (retired from pages, kept as source). `-480`/`-560` files are responsive derivatives.
